## Integración y distribución

La publicación se realiza desde main tras aprobar sus checks obligatorios.
La validación real de cotizaciones del PR #81 confirmó que el lector usa el
mismo DLR/SPOT que la cabecera de Cocos 4.24.4. La candidata 0.0.28 no se instaló
en el perfil del usuario; no se presenta el fixture como integración instalada.

La publicación de GitHub no instala ni actualiza extensiones automáticamente,
ni publica en Chrome Web Store. No se modificaron registros ni dashboards reales
ni se enviaron órdenes. Se retiran sólo pestañas y servidores de fixtures;
el navegador compartido y Cocos se conservan.
