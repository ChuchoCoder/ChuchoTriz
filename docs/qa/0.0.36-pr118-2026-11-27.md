# QA de arranque de widgets guardados

ChuchoTriz Free 0.0.36. Build revisado `6c2aab0` y base `5c269a9`. Ejecutado el 27 de noviembre de 2026 en el perfil compartido ChuchoTriz Free, Chrome 156.0.8078.80. El fixture usa datos simulados y el paquete de producción servido por HTTP en loopback.

## Rendimiento

CPU limitada a 4× y caché desactivada. Se postergó 5,5 s la publicación del store, con un widget nativo y dos espacios guardados presentes desde el principio. Tres corridas por build. La espera se mide desde la publicación efectiva del store hasta el montaje de Ratios y Dólar intradiario. Los tiempos de JavaScript y del hilo principal incluyen el fixture, desde la navegación hasta que se detecta el gráfico. Los valores son mediana y rango en milisegundos.

| Métrica | Base | Revisado |
| --- | ---: | ---: |
| Store listo a widgets montados | 3.979 (3.688–3.994) | 157 (23–162) |
| JavaScript | 1.223 (998–1.463) | 1.030 (972–1.054) |
| Hilo principal | 3.041 (2.427–3.469) | 2.424 (2.193–2.707) |
| Lecturas internas hasta el montaje | 5 (5–5) | 11 (11–12) |

En un escenario adicional de 4,2 s, la base alcanzó el último reintento corto en dos corridas. El rango fue 46–4.664 ms para la base y 252–383 ms para el build revisado. El costo y la latencia dependen de cuándo queda listo Matriz respecto de los intervalos programados. Las comprobaciones adicionales del escenario tardío terminan antes de suscribir o leer cotizaciones mientras falta el store.

Con dos pestañas que Chrome reportó visibles, durante 5,5 s de operación después del montaje, la base registró 6 y 6 lecturas internas de estado o cotizaciones y el build revisado registró 6 y 5. Una corrida por build.

## Navegador

`node tools/qa/run.mjs --smoke --group=widget-startup` dio 16 PASS en el build revisado, ocho por tema. La prueba inicia con espacios guardados, retrasa el store o el layout mediante el fixture y verifica el montaje y la lectura según visibilidad. Se combinaron clics con cambios controlados del fixture.

| Caso | Entorno | Tema | Estado | Observado |
| --- | --- | --- | --- | --- |
| Arranque tardío y cotizaciones | Fixture | Oscuro | PASS | Montaje 157 ms después del store; tabla y gráfico con datos. |
| Arranque tardío y cotizaciones | Fixture | Claro | PASS | Montaje 154 ms después del store; tabla y gráfico con datos. |
| Reposo y recorte | Fixture | Oscuro | PASS | Cero lecturas tras el arranque cuando se ocultan o recortan los widgets, al cambiar a un tablero vacío y tras vencer el plazo de un slot sin configuración. |
| Reposo y recorte | Fixture | Claro | PASS | Cero lecturas en los mismos recorridos. Recuperación al mostrar el espacio y completar el layout. |
| Arranque instalado | Matriz | Claro y oscuro | NOT RUN | Repetir cuando esté disponible una sesión autenticada con un tablero que tenga Ratios y Dólar intradiario guardados. |
