## Cambios desde 0.0.29

- Futuros de A3 como referencia C en el widget y el Monitor, por ejemplo
  DLR/NOV26 y DLR/DIC26. Identidad exacta por vencimiento, precio publicado
  sin multiplicador de contrato y restricción a sólo monitor.
- Apertura del gráfico con indicadores, comparaciones y dibujos heredados
  retirados de esa pestaña. Agrega sólo Ratio A/B con línea blanca y la
  comparación B o C a izquierda numérica, manteniendo velas de cinco minutos.
- Se conservan los diseños guardados de Matriz y las otras pestañas.

La preparación actualiza manifest/package/lock, README e informe/allowlist.
No cambia runtime, dependencias ni permisos respecto del PR #89 integrado.

## Distribución

Paquete previsto: `chuchotriz-free-0.0.30.zip`, manifest en raíz y permiso único
storage; se adjuntará su archivo `.sha256`. GitHub aloja el paquete para publicar;
la carga a Chrome Web Store queda a cargo del usuario.

Los fixtures se ejecutan en loopback con el servidor Playwright del perfil
ChuchoTriz, sin abrir un perfil aislado ni cerrar el navegador compartido.
No se recargó la extensión instalada ni se alteraron datos reales para esta
preparación. No se enviaron ni cancelaron órdenes.
