# QA de cotizaciones intradiarias compartidas

ChuchoTriz Free 0.0.36. Build `924497e` y base `eeeb3ad`. Ejecutado el 27 de noviembre de 2026 en Chrome compartido ChuchoTriz Free. El fixture sirve ambos paquetes de producción por HTTP en loopback con datos simulados.

## Rendimiento

CPU limitada a 4×. Tres ventanas nominales de 5,5 s por build y cantidad de gráficos visibles con el mismo par. Cada ventana aplicó 13 cambios de precio en el fixture. Los tiempos de JavaScript y del hilo principal son los totales de Chrome durante la ventana, incluido el trabajo del fixture. Se muestra la mediana y el rango observado.

| Métrica | Base | Cotizaciones compartidas |
| --- | ---: | ---: |
| Lecturas internas con un gráfico | 3 (2–3) | 3 (2–3) |
| Lecturas internas con cuatro gráficos | 11 (9–11) | 3 (2–3) |
| JavaScript con cuatro gráficos | 299 ms (290–347) | 289 ms (219–357) |
| Hilo principal con cuatro gráficos | 718 ms (604–721) | 456 ms (445–610) |
| JavaScript con un gráfico | 116 ms (107–166) | 103 ms (75–110) |
| Hilo principal con un gráfico | 250 ms (216–316) | 206 ms (197–247) |

En una ventana adicional de 5,5 s, con dos pestañas que Chrome reportó visibles y cuatro gráficos por pestaña, se pasó de 8 + 8 lecturas a 2 + 2. Las cifras cuentan solicitudes internas al lector de cotizaciones. El costo de JavaScript y renderizado varía con la cadencia y la carga del navegador.

## Verificación después de la revisión

Se repitió la medición con `main` en `4fbc181` y el build `e6b0b7c`, que incluye el histórico diario y Referencia C. Se usó Chrome compartido, datos simulados y CPU limitada a 4×, con tres ventanas de 5,5 s y 13 cambios de precio por ventana. Los tiempos incluyen el trabajo del fixture.

| Métrica | Base | Candidato revisado |
| --- | ---: | ---: |

| Hilo principal con cuatro gráficos | 371 ms (286–465) | 183 ms (162–266) |

En cada tema pasaron 8 casos de cotizaciones compartidas, 50 de Intradiario, 23 de Histórico diario, 13 de Ticket y Tenencia y 3 de Cantidades rápidas. Los casos nuevos demoran deliberadamente una respuesta para comprobar que la reapertura use la cotización vigente y que los gráficos restaurados reciban la primera lectura de su grupo.

Pasaron seguridad, 651 pruebas Vitest, 120 pruebas Node, empaquetado y auditoría. La ruta predeterminada del launcher ya no estaba disponible en este equipo. Los casos de navegador indicados se ejecutaron por el MCP del perfil compartido Free con el paquete de producción. La regresión completa de navegador y la verificación del paquete instalado en Matriz real quedan pendientes.
